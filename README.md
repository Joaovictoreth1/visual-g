# Situação escolar em VisuAlg

`SITUACAO_ESCOLAR_INTERATIVA123.ALG` lê a média de um aluno e imprime sua situação.

No VisuAlg 3 para Windows, abra o arquivo `.ALG`, pressione **F9** e digite uma média numérica. Preserve a codificação legada compatível com Windows-1252 e as quebras de linha CRLF ao salvar; o arquivo não foi convertido para UTF-8.

| Média | Saída esperada |
|---|---|
| `4,9` | `Reprovado(a)` |
| `5` | `Recuperação` |
| `6,9` | `Recuperação` |
| `7` | `Aprovado(a)` |

Para médias decimais, use o separador decimal aceito pela sua instalação. Estes exemplos são casos de verificação manual.
